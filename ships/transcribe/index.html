Long recording?

Get the desktop version.

This page keeps the whole recording in memory, so somewhere past an hour your browser may give up. The desktop version runs the same job as an ordinary program on your computer, with no length limit, no internet needed, and roughly fifteen times faster than real time. Your file stays on your machine either way.

macOS Apple Silicon (M1 and newer) Download .dmg macOS Intel processor Download .dmg Windows Windows 10 and 11, 64-bit Download .exe

Not sure which Mac you have? Apple menu, then About This Mac. If it mentions M1, M2, M3 or M4, take the Apple Silicon one.

You will see a security warning, and you should know why. These downloads are not code-signed, because signing certificates cost money every year and this is free. So macOS and Windows will both tell you the developer is unverified. Nothing is wrong with the file, but please do not take that on trust from me.

Read the code instead. Every line is on GitHub, and every download is built there in public from that source, so you can see exactly what went into the file before you run it. The installation instructions are in the README.
